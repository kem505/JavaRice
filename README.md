# JavaRice - Profile Card

A modern, responsive profile card built with HTML, CSS, and JavaScript.

## Features

- 🎨 Modern gradient design with smooth animations
- 📱 Fully responsive layout for mobile and desktop
- ⚡ Interactive buttons (Follow/Message)
- 📊 Profile statistics display
- 🔗 Social media links (GitHub, LinkedIn, Twitter)
- ✨ Smooth hover effects and transitions
- 🎯 Clean and minimal design

## How to Use

1. Open `index.html` in your web browser
2. Customize the profile information in the HTML file:
   - Update name, title, and description
   - Change profile image URL
   - Modify statistics values
   - Update social media links

## File Structure

```
├── index.html   # Main HTML structure
├── styles.css   # CSS styling and animations
├── script.js    # JavaScript for interactive features
└── README.md    # This file
```

## Customization

### Profile Image
Replace the placeholder image URL in `index.html`:
```html
<img src="your-image-url" alt="Profile Picture">
```

### Colors
Modify the gradient colors in `styles.css`:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### Content
Edit the profile information directly in `index.html`:
- Name: Update the `<h1>` tag
- Title: Update the `<p class="profile-title">` tag
- Description: Update the `<p class="profile-description">` tag
- Stats: Modify the stat values in the `.stat` divs
